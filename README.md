# DuoFlick

iPhone Duo の外側画面で打ちやすいフリック入力キーボードを作るためのプロジェクトです。
キーボードの設定（地球儀キーを上にフリック）から、形（標準・右寄せ・扇形）や大きさを実機で調整できます。

Mac も有料の Apple Developer Program も使わずに、次の流れで iPhone に入れます。

1. GitHub に変更を送ると、GitHub Actions が Mac 上でアプリをビルドする（署名なし）
2. できた `DuoFlick.ipa` を Windows の PC にダウンロードする
3. Sideloadly で、無料の Apple ID を使って署名し、iPhone に入れる

## 初回だけの準備

### Windows の PC

1. Apple の「Apple Devices」アプリ（または iTunes）を入れる。iPhone を USB でつないだとき PC が認識するために必要です
2. [Sideloadly](https://sideloadly.io/) を入れる

### iPhone

1. 「設定」→「プライバシーとセキュリティ」→「デベロッパモード」をオンにする（iPhone を PC につないで一度 Sideloadly でインストールを試すと、この項目が表示されます）

## ビルドしてインストールする

1. GitHub のこのリポジトリの「Actions」タブを開き、左の「build」→ 右の「Run workflow」→「Run workflow」を押す。一番上の実行が緑のチェックになるまで待つ（初回は辞書の取得で10分前後）
2. その実行を開き、下の「Artifacts」にある `DuoFlick-ipa` をダウンロードして展開する
3. iPhone を USB で PC につなぎ、Sideloadly を開く
4. `DuoFlick.ipa` を Sideloadly にドラッグし、Apple ID を入力して「Start」を押す
5. iPhone で「設定」→「一般」→「VPNとデバイス管理」を開き、自分の Apple ID を「信頼」する（初回のみ）

## キーボードを使う

1. 「設定」→「一般」→「キーボード」→「キーボード」→「新しいキーボードを追加」で DuoFlick を追加する
2. 文字を入力できる場所で地球儀ボタンを長押しし、DuoFlick を選ぶ
3. 地球儀キーを上にフリックすると設定画面が出る。大きさは「キーを見ながら調整」で、キーボードを見ながらスライダーで変えられる

## 無料の Apple ID で使うときの注意

- 7日で署名が切れて起動しなくなります。Sideloadly の自動更新を有効にし、PC を起動して iPhone と同じ Wi-Fi につないでおくと、自動で入れ直されます
- 自作アプリは同時に3つまでしか入れられません

## キーボードの操作

- 左の列：上から「数字」「地球儀」「ABC（かな⇄英字）」「片手／両手（持ち方の切り替え）」
- 数字キー：押したまま右上に大きめに動かすと0〜4、右下だと5〜9の枠が指の位置に大きく出る。指を数字の上に動かして離すと、その数字が入る（真ん中は0か5）。タップだけでは何も入らない（片手・左手のときは左右が逆）
- フリックのガイドはiOS標準と同じく、押すと周りの文字が出て、方向を選ぶとその文字が吹き出しで大きく出る
- 地球儀キー：タップでキーボードの切り替え、上フリックで設定、左フリックで定型文、右フリックでクリップボードの履歴
- 持ち方の切り替え：片手持ち用と両手持ち用で、形・大きさ・余白などを別々に覚える
- 英字はパソコンと同じ並び。⇧で次の1文字を大文字、続けて2回で大文字に固定。「123」で数字と記号、「#+=」でそのほかの記号。一番下の「A／あ」キー（パソコンの全角／半角キーと同じ）で英字と日本語を切り替える。「あ」のときはローマ字で打つとかなになり、変換できる
- ⌫を左にフリックすると入力中の文字か直前の語をまとめて消し、右にフリックすると直前の確定を取り消して読みに戻す
- 入力欄の種類に合わせて文字種が切り替わる（メール・URL欄は英字、電話番号欄は数字と記号）
- 空白キーを長押しして上下左右に動かすと、入力位置（カーソル）が動く。上下は改行で区切られた行が対象
- 変換中に空白キーを長押しして左右に動かすと、文節の区切り（どこまでを変換するか）が変わる
- 入力したひらがなは上の帯に変換候補が出る。候補をタップで確定、空白キーで次の候補、改行で確定。帯の右端の ∨ で候補の一覧を広げられる
- 入力中は改行キーが「確定」、空白キーが「次候補」に変わる。入力欄に合わせて改行キーが「検索」「送信」などになり、青く表示される
- 確定すると、上の帯に次に続きそうな言葉（予測）が出る。よく選ぶ候補は学習して上に出る
- 設定「続けてタップで文字を切り替え」をオンにすると、同じキーを続けてタップしたとき文字が切り替わる（あ→い→う…）。初期はオフ
- 設定「単語登録」：入力欄で単語を選択してから開き、下のかなキーで読みを入れて「登録」。「辞書の一覧」で確認・削除できる
- 絵文字は地球儀キーでiOSの絵文字キーボードに切り替える。変換候補にも絵文字が出る（例：わらう）
- 設定「打ち比べで最適化」：お題をAとBの設定で打ち、時間とミスを見て選ぶ。選んだほうへ少しずつ絞り込む（お題の入力は入力欄に入らない）
- クリップボードの履歴は、キーボードを開いている間にコピーした文字だけが残る。「編集」から項目を固定すると、件数の上限で消えなくなる。設定アプリで DuoFlick の「フルアクセスを許可」をオンにする必要がある（振動も同じ）
- 外側画面と、開いた内側画面とで、別々の設定を覚える
