# 同梱している SKK 辞書データについて

`Keyboard/SkkDict/` は、次の SKK 辞書から、AzooKey の辞書にない語を選んで作った辞書ファイルです（作り方は `tools/make_skk_dict.py`）。

- SKK-JISYO.L
- SKK-JISYO.propernoun
- SKK-JISYO.jinmei
- SKK-JISYO.station

元の辞書は https://github.com/skk-dev/dict にあります。それぞれの著作者とライセンス（主に GNU General Public License v2 以降）は、各辞書ファイルの先頭の注記と、そのリポジトリの README に従います。

この辞書データを含む DuoFlick のソースコードは、このリポジトリで公開しています。
